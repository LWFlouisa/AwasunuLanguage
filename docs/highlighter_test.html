Gene Sequencing Tests

The Awasunu scripting language seems to have its own preferences for what hair colors and eye colors it prefers.

Basic Genetic Test

The first genetic tests using the scripting language.

  -- This is a test script in Awasunu Sector Four, a subset of Awasunu.
  obelisk1 this_is_an_awasunu_sector_four_test
  obelisk4 this_message is_split into_four sections_of_text

  scash

Intermediate Test

The second genetic tests using the scripting language.

  obelisk3 hair_color_is_medium_dark_brown eye_color_is_yellow brown_skin_tone

  obelisk3 hair_color_is_strawberry_with_dark_red_streaks eye_color_is_green_yellow pale_skin_tone

Advanced Awasunu

Characters seem to evolve and develop hybrid hair colors where they'll have a base color with odd color streaks.

  obelisk3 hair_color_is_dark_brown eye_color_is_green light_medium_brown_skin_tone
  obelisk3 hair_color_is_bright_red brown_skin_tone eye_color_is_black
  obelisk3 hair_color_is_black_with_yellow_streaks eye_color_is_dark_blue brown_skin_tone
  obelisk3 hair_color_is_medium_brown_with_strawberry_streaks eye_color_is_green_yellow light_tan_skin_tone
  obelisk3 hair_color_is_blond eye_color_is_light_green pale_skin_tone

  scash
